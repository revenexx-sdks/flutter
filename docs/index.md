## Getting Started

### Init your SDK

Initialize your SDK with your Revenexx API endpoint and your credentials. The client supports two authentication methods:

- **Bearer token** — a Zitadel-issued JWT for an interactive end-user, set via `setBearerAuth()`. The value is sent as the `Authorization` header verbatim, so include the `Bearer ` prefix. This is the recommended method for client apps.
- **API key** — a gateway-managed scoped key (`rvxk_…`), set via `setApiKeyAuth()`. Intended for server-side or trusted environments; never embed an API key in an app shipped to end users.

Scope every request to a tenant with `setTenant()`, which sends the `X-Revenexx-Tenant` header on each call.

```dart
import 'package:revenexx/revenexx.dart';

Client client = Client()
    .setEndpoint('https://api.revenexx.com') // Your Revenexx API endpoint
    .setTenant('<TENANT_SLUG>')              // The tenant your requests are scoped to
    .setBearerAuth('Bearer <JWT>');          // The signed-in user's JWT
```
